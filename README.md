# Todo App

A professional and minimalistic Todo App built with React, Vite, Context API, and Tailwind CSS. This app allows users to manage their daily tasks efficiently, featuring a clean and responsive user interface.

## Features

- **Add Tasks**: Easily add new tasks to your list.
- **Edit Tasks**: Modify task details as needed.
- **Delete Tasks**: Remove tasks once completed or unnecessary.
- **Task Status**: Mark tasks as completed or pending.
- **Responsive Design**: Optimized for all screen sizes.
- **Persistent State**: Retain task list data using local storage.

## Technologies Used

- **React**: For building the user interface.
- **Vite**: As the development build tool for faster performance.
- **Context API**: For state management across components.
- **Tailwind CSS**: For styling the app with utility-first CSS classes.

## Installation

Follow the steps below to set up and run the Todo App locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/todo-app.git
   ```

2. Navigate to the project directory:
   ```bash
   cd todo-app
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to:
   ```
   http://localhost:5173
   ```

## Usage

1. Open the app in your browser.
2. Add tasks using the input field and "Add" button.
3. Manage tasks by marking them as complete, editing, or deleting.
4. Enjoy a clean and responsive experience across devices.
